# BGI — Buddha Group of Institutions website

A responsive, static website concept created using HTML, CSS and vanilla JavaScript.

## Run
Open `index.html` in a browser. No build tools or paid services are required.

## Included
- Institutional overview and links to BIT, BPC and BIM official websites
- Institute programme summaries based on the official websites checked on 18 November 2026
- Buddha Innovation Council social link
- Tech-Genesis 11.0 event details, categories, countdown and college contact links
- Responsive navigation and campus/project photo gallery
- Social media links supplied by the site owner
- Website creator attribution in the footer

## Important notes
- This is an independent website concept, not an official BGI website. Obtain written institutional approval before publishing it as an official site or using institutional logos/branding.
- The registration/contact section links to the phone numbers printed on the supplied event poster. There is no server-side registration database or automatic registration confirmation.
- The creator's email and phone number are displayed publicly because they were explicitly requested. Consider using a supervised project email or a college-approved contact address before publishing, especially on a public website.
- Event details are transcribed from the supplied TECH-GENESIS 11.0 poster. Confirm schedule, rules and availability with the college.
- Institute details and programme summaries should be checked against the live official sites before public launch.
